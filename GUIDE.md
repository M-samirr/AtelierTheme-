# دليل التاجر: ثيم وشاح

> English version below.

وشاح ثيم تحريري لمتاجر الأزياء والجمال على منصة سلة. يعمل بالعربية والإنجليزية، ويتكيف مع الجوال والحاسوب.

## البدء

1. ثبّت الثيم من متجر ثيمات سلة وفعّله.
2. افتح **المتجر الإلكتروني > تخصيص الثيم**.
3. ارفع شعار المتجر، واختر اللون الأساسي والخط من إعدادات المتجر العامة.
4. رتّب مكونات الصفحة الرئيسية، ثم احفظ.

## مكونات الصفحة الرئيسية

| المكوّن           | الاستخدام                              |
| ----------------- | -------------------------------------- |
| الواجهة التحريرية | صورة كبيرة بعنوان وزر في أعلى الصفحة   |
| تسوق الإطلالة     | صورة تعرض المنتجات الظاهرة فيها        |
| مجموعات بتبويبات  | عدة مجموعات منتجات في مكان واحد        |
| تخفيضات سريعة     | عرض بعدّاد تنازلي                      |
| قصة العلامة       | نص وصورة عن علامتك                     |
| المزايا والمكونات | مزايا المنتج أو مكوناته                |
| معرض العملاء      | صور من عملائك                          |
| الأسئلة الشائعة   | أسئلة وأجوبة قابلة للطي                |
| آراء العملاء      | تقييمات تكتبها أنت                     |
| شريط الماركات     | شعارات الماركات                        |
| من المدونة        | أحدث المقالات                          |
| فيديو مميز        | فيديو يوتيوب لا يُحمَّل إلا عند تشغيله |

تعمل كذلك مكونات سلة الأساسية، مثل صور متحركة ومنتجات مختارة.

## الإعدادات

| القسم         | ما يمكنك تغييره                                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------------------------------- |
| الشكل العام   | شكل الزوايا، الحركات الانتقالية                                                                                       |
| رأس الصفحة    | التخطيط، التثبيت عند التمرير، لون الشريط العلوي ونصه ورابطه، الشريط السفلي على الجوال                                 |
| التذييل       | التخطيط، الوضع الداكن، نبذة المتجر، طرق الدفع                                                                         |
| بطاقة المنتج  | شكل الصورة، تأثير المرور، زر الإضافة، التقييم، زر أعلمني عند التوفر                                                   |
| صفحة المنتجات | موضع الفلاتر، طريقة العرض، عدد الأعمدة، مسار التنقل                                                                   |
| صفحة المنتج   | طريقة عرض الصور وملاءمتها، عرض الوصف، الوسوم، المنتجات المشابهة، شريط الشراء الثابت، مزايا بجانب زر الشراء، قسم إضافي |

## نصائح

- **الصور:** استخدم صور المنتج بنسبة موحدة، ويفضل 4:5.
- **الصورة الأولى:** تظهر مباشرة عند فتح صفحة المنتج، فاختر أوضح صورة.
- **مزايا بجانب زر الشراء:** اكتب ميزة واحدة في كل سطر، ويظهر أول أربعة أسطر.
- **النصوص البديلة للصور:** أضفها عند رفع الصور داخل الصفحات والمقالات، فهي تفيد ضعاف البصر ومحركات البحث.

## الدعم

للمساعدة، تواصل معنا عبر وسائل الدعم الظاهرة في صفحة الثيم على متجر ثيمات سلة.

# Merchant guide: WishahStudio theme

WishahStudio is an editorial theme for fashion and beauty stores on Salla. It works in Arabic and English, on phones and desktops.

## Getting started

1. Install the theme from the Salla Themes Marketplace and activate it.
2. Open **Online store > Customize theme**.
3. Upload your logo and choose your primary colour and font in the store's general settings.
4. Arrange the home page blocks and save.

## Home page blocks

| Block              | Use it for                                                      |
| ------------------ | --------------------------------------------------------------- |
| Editorial hero     | A large image with a headline and button at the top of the page |
| Lookbook           | One photo that shows the products in it                         |
| Collection tabs    | Several product collections in one place                        |
| Flash sale         | An offer with a countdown                                       |
| Story band         | Text and an image about your brand                              |
| Notes and benefits | Product benefits or ingredients                                 |
| Customer gallery   | Photos from your customers                                      |
| FAQ                | Questions and answers that fold open                            |
| Customer reviews   | Reviews you write in yourself                                   |
| Brand strip        | Brand logos                                                     |
| Journal teaser     | Your latest articles                                            |
| Video feature      | A YouTube video that loads only when played                     |

Salla's standard blocks, such as photo sliders and chosen products, also work.

## Settings

| Section         | What you can change                                                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Overall look    | Corner style, motion                                                                                                                 |
| Header          | Layout, sticky on scroll, top bar colour, text and link, phone bottom bar                                                            |
| Footer          | Layout, dark mode, store summary, payment methods                                                                                    |
| Product card    | Image shape, hover effect, add button, rating, notify-me button                                                                      |
| Product listing | Filter position, default view, number of columns, breadcrumbs                                                                        |
| Product page    | Gallery style and fit, description layout, tags, similar products, sticky buy bar, benefits beside the buy button, one extra section |

## Tips

- **Photos:** keep product photos to one shape, ideally 4:5.
- **First photo:** it appears as soon as the product page opens, so choose your clearest one.
- **Benefits beside the buy button:** write one per line. The first four lines are shown.
- **Image descriptions:** add them when you upload images in pages and articles. They help customers with low vision and search engines.

## Support

For help, use the support channels shown on the theme's page in the Salla Themes Marketplace.
